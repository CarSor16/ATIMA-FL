Dal profilo al confronto
ATIMA: Adversarial Testing Infrastructure for Model Aggregation. FL indica il contesto Federated Learning.
  1. Scegli componenti, dati, seed e budget. I parametri mostrati provengono dai file dei componenti.
  2. Verifica la configurazione ed esporta il piano. Il salvataggio non avvia un training.
  3. Trasferisci il piano nel cluster. In New Batch Job richiedi una GPU reale e le CPU indicate.
  4. Esegui bash run_cluster.sh preflight. Dopo il controllo, esegui bash run_cluster.sh train.
  5. Completa prima la clean, poi l’attacco abbinato. Esporta metriche e artefatti utili per l’analisi.
  6. Analizza con atima analyze --clean ... --attack ... --output .... Per più seed usa atima statistics.
Aggiungere un componente
Un file Python nella cartella della sua categoria, con PLUGIN, parametri e hook. Usa atima ui --plugins plugins per caricare componenti esterni. Se rimuovi un file, la configurazione che lo selezionava viene respinta esplicitamente.
Interpretazione
Le verifiche locali dimostrano il comportamento software delle fixture. Prestazioni, efficacia degli attacchi e uso GPU richiedono esperimenti nel cluster. I round non sono repliche statistiche indipendenti.
